# 单人物叙事轨迹

“人物行踪”页一次展示一个选中人物，不需要第二个人物或对照操作。切换人物会立即重建该人物自己的地点节点和顺序连线。

## 节点与连线

- 节点从本项目的 `character_mentions.jsonl` 与 `place_mentions.jsonl` 逐段关联；人物和地名必须出现在同一段。
- 一个段落里的同一地名只保留一个地图节点，避免重复词面跨度堆叠。节点按章节、段落和词面出现位置排序。
- 坐标只取 `geocoding_results.jsonl` 中历史地名志筛查为 `OK`，且年代状态为 `OVERLAPS_PROJECT_ANALYSIS_WINDOW` 或 `HISTORIC_PERIOD_UNKNOWN` 的记录。不会用现代地名志坐标补成古代轨迹。
- 地图按唯一坐标画点；按叙事顺序连接相邻的不同坐标。若一个人物只有一个有效位置，地图显示单点与原文出处，不要求形成线。
- 地名标签保留原文词面。点位弹窗显示章节、段落、MED 和审查限制；点击原文按钮可打开对应段落。出处列表点击后会定位到地图点。

这些是小说文本中的“同段共现地点候选”，不是人物旅行日志，也不证明人物到访了相关地点。地点同名解析、历史身份和数据词典误匹配仍需逐条人工核验；线段只是叙事顺序的直线示意，没有道路含义。自动浏览器验收检查单人物切换、多点连线、单点保留、点位标签及原文跳转，结果保存在 `outputs/logs/browser_acceptance.json`。
