# 人物动态、地名档案与地图问答

本轮只扩展前端展示和本地检索，未改动语料、地名志、坐标筛查、His-Geo 算法或原有研究输出。地图问答无网络后端，无付费 API。

## 人物动态

进入“人物行踪”，默认显示单个人物完整轨迹。点击“播放轨迹”从原文序号 001 开始；中途暂停后继续播放。可以拖动进度、逐章前后移动、从头开始，选择 0.5×、1×、2×、4×，或勾选“跟随最新证据”。地图右上角复位恢复完整进度和视野。

“多人对比”默认选刘备、曹操、孙权，可选 0–4 人。各人物独立配色、独立连线，共用 001–119 的原文章节文件进度。没有证据的章节显示无新增；未出现的点不提前绘制。亮环表示各人物最近一条证据，不是模拟该人物此时的实际位置。

节点继续由 `collectTrackNodes()` 使用原来的规则生成：只接受历史库筛查唯一成功、年代重叠或未知、坐标有效的人物—地名同段共现；按章节、段落、词面位置和地名排序；同段同名去重，连线只移除连续相同坐标。不插值，不推断移动速度，不跨人物连线。原始第 65 个文件重新编号的章名保留不变。

切换人物、模式、选择集合、离开页面、标签页隐藏、打开地点档案或手动选择证据都会停止播放；倍速变更保留当前进度。没有任何有效节点时播放按钮禁用。减少动态效果的系统设置关闭亮环闪烁，但仍允许主动逐章播放。

## 地名档案

直接单击总览或人物地图的古地名标签/圆点打开弹窗。同坐标不同词面分别列为切换按钮，不将它们自动认定为同义词。事件地图弹窗也有地点介绍按钮。历史地名列表保留原有定位和证据面板，并在面板增加“地点介绍与叙事档案”入口；未运行地理编码的地名仍可展示文本档案。

介绍来自当前文本提及次数、不同段落和章节数量、同段共现人物、最集中的章节，不调用外部百科。档案分别展示主流程（可能为现代参照）和历史库独立筛查的经纬度/MED，并附可跳转的原文段落。匹配地名志的年代及别名只在实际匹配 ID 对应记录下展示，不将晚期名称直接认作三国地名。未定位记录不伪造坐标。

## 地图问答

这是规则驱动的本地检索与统计助手，并非调用大模型的通用智能体。会显示这一能力边界。问答记录保留在当前页面内存，刷新即清除。

支持的实际查询包括：

- “洛阳有什么故事？”：叙事统计、共现人物、主流程与历史筛查位置、原文片段。
- “洛阳和成都的数据对比”：逐地名的同口径提及/段落/章节数与坐标来源。
- “刘备与洛阳有什么关联”：不同段落去重后的人物—地名共现证据。
- “刘备和曹操有哪些共同地名？”：各人物分别出现的地名集合交集，按各人物段落数的最小值降序排列；不解释为同地会面。最多比较四人。
- “刘备的轨迹经过哪些地方？”：历史库筛查通过的候选地点、证据及动态地图入口。
- “洛阳有哪些战争事件线索？”：该地名所在段落的各类事件候选统计，明确为规则候选，不能解释为发生于此的真实战役清单。
- “地图里有什么有趣的现象？”：按不同段落数的高频地名、最集中章节与高频词面缺少历史坐标的数量；均以当前数据计算，不编写人物轶事。

未匹配的问法给出支持范围；历史事实、死亡地点、因果类问题明确不作独立断言。当前不支持自由语义推理、史料核实或多步研究任务。每次有证据的回答附段落 ID、原始章名、摘录与阅读跳转；输入按文本处理，不作为 HTML 执行。

统计口径：一次提及对应 `place_mentions.jsonl` 一行；段落/章节按 ID 去重；人物同段数量按人物 ID 和段落 ID 去重。地名词面之间没有自动语义归并，章节序号不是公历年份。高频前 20 的历史坐标缺口以独立历史筛查状态为准。

## 验证

现有 Python 数据契约测试保持 8 项，新增行为由 `scripts/check_track_assistant.cjs` 接入完整浏览器回归：暂停后进度不变、回拖不提前显示节点、对比线坐标逐项等于各人物筛查节点、人数上限/空选择、切换停止、地点标签单击与原文跳转、问答计数与有效证据 ID、地图联动、未知问题/输入转义，以及 390/320px 手机操作。全套 `scripts/check_frontend.cjs` 同时检查八个页面、两种主题、所有本地 HTTP 和外部请求。
