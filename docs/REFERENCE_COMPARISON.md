# 参考项目对照

参考项目：[`wonton1984/sanguo-map`](https://github.com/wonton1984/sanguo-map)。本项目借鉴页面组织与地图交互的产品思路，并向项目作者致谢。

## 参考项目提供的设计经验

其 README 展示了地图与章节时间轴联动、人物轨迹、原文阅读、事件卡跳转、人物/地点/事件数据结构、图层开关、移动布局和本地 Leaflet。数据主要以 JavaScript 事件、人物、地点、轨迹文件供静态页面加载；其自述事件、人物和地名数量与章节版本按该仓库自己的 120 回整理口径。

这些功能说明交互模式可行，但其整理好的事件摘要、年份、坐标、人物轨迹、原文、历史对照、图片和边界数据均**没有被导入本项目，也没有被当作从本地 119 章抽取的结果**。本项目自身的记录只由单独的 EPUB 转换语料、项目自有词典规则及冻结 His-Geo gazetteer 构建，并带来源指针。随用的 Leaflet 发行文件按自身许可证另行记录，不属于参考项目的自有数据素材。

## 本项目独立实现

本项目新增了 119 章原文解析及版本核验、段落字节偏移和哈希、人物别名词面提及、His-Geo CHGIS 精确地名面匹配、事件/时间候选、保守地理编码状态、MED/Geocoder trace、SQLite 关系表、共现网络、叙事顺序轨迹、局部米制战场缓冲和描述性核密度。以上均是本项目独立代码；它们不是参考仓库中人工整理内容的改名复制。

## 许可与素材

参考仓库根目录标注 MIT 许可，并另行声明头像、阿里云行政区数据及其他素材按照各自授权传播。因此本项目没有复制参考仓库的事件、人物、图像、边界或 ECharts 数据。仅将其随附的 Leaflet 1.9.4 JS/CSS 文件用于本地交互地图；Leaflet 自身采用 BSD-2-Clause，随文件保留上游许可证与版权声明，来源项目 commit、文件 SHA-256 和许可分别记录在 `frontend/assets/vendor/ASSET_ORIGIN.md` 与 `frontend/assets/vendor/leaflet-LICENSE.txt`。当前底图另使用 Natural Earth 公共领域矢量数据，来源和哈希见 `docs/BASEMAP.md`，不来自参考仓库。地图不依赖在线瓦片。
